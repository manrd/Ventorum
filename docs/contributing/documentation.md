# Documentation and code standards

| Item | Standard |
| --- | --- |
| Language of comments, docstrings and documents | Simple technical English following ASD-STE100: short sentences, active voice, one instruction per sentence. Do not use the em dash character. |
| Docstrings | NumPy docstring standard, checked by ruff (`D` rules, numpy convention). Give the unit of every physical quantity (m, m/s, rad, deg, kg/m^3, N). |
| Code style | PEP 8, checked by `ruff check .` |
| References | Each model gives its sources in its docstring and in the theory manual, with credit to the authors. |
| Numbers in documents | Generated by a script from the code, never typed by hand. |

## Build the documentation

```bash
pip install -e .[docs]
sphinx-build -W --keep-going -b html docs docs/_build/html
```

The build fails on any warning, so broken references and malformed docstrings are found at once. The agent tool reference is generated from the live MCP schemas at each build.
